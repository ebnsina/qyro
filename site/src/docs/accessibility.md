# Accessibility and keyboard

## Keyboard

Focus the player (click it or <kbd>Tab</kbd> to it), then:

| Keys | Does |
| --- | --- |
| <kbd>Space</kbd> or <kbd>K</kbd> | Play or pause |
| <kbd>J</kbd> / <kbd>L</kbd> | Back or forward 10 seconds |
| <kbd>←</kbd> / <kbd>→</kbd> | Back or forward 5 seconds |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Volume up or down |
| <kbd>0</kbd> – <kbd>9</kbd> | Jump to 0% – 90% |
| <kbd>Home</kbd> / <kbd>End</kbd> | Start or end (live: go to live) |
| <kbd>M</kbd> | Mute |
| <kbd>C</kbd> | Captions |
| <kbd>F</kbd> | Full screen |
| <kbd>?</kbd> | Show these shortcuts |
| <kbd>Shift</kbd> + <kbd>F10</kbd> or the menu key | Player menu |

In menus, arrow keys move, <kbd>Enter</kbd> chooses, <kbd>Esc</kbd> goes back.

## Screen readers

- Every control has a label that says what it does now ("Play", "Pause", "Exit full screen").
- The seek bar is a slider that reads "1 minute, 5 seconds of 10 minutes".
- Seeking, volume, captions and quality changes are announced.
- Menus use menu roles, with checked states for choices.

## Touch

- Tap shows or hides the controls; it never pauses by accident.
- Double-tap the left or right side to skip 10 seconds.
- Long-press opens the player menu.
- Every target is at least 44px.

## Motion

With *Reduce motion* turned on, everything fades instead of moving, and the live dot stays still.
